# Python Sandbox

Личный учебный репозиторий с небольшими Python-скриптами, экспериментами и задачами для практики.

**Назначение:** здесь можно сохранять разные способы решения одной задачи, изучать Python и pytest и видеть прогресс. Это не production-проект и не демонстрация готовой библиотеки.

## Существующие скрипты

| Файл | Назначение | Что учесть |
| --- | --- | --- |
| `compare_json.py` | Сравнение наборов идентификаторов из двух JSON-файлов | Сейчас использует абсолютные пути к локальным файлам: для запуска их нужно заменить |
| `convert_second_to_date.py` | Преобразование Unix timestamp в дату и время | Учебный пример со стандартной библиотекой |
| `find_prime_factors.py` | Эксперимент с разложением целого числа на простые множители | Реализация учебная; полнота для произвольных входных чисел не подтверждена |
| `myself_created_task.py` | Поиск следующего отправления по заданному расписанию | Скрипт получает время через `input()` |

## Пример запуска

После клонирования репозитория из корневой папки:

```bash
python3 convert_second_to_date.py
```

Для скриптов с `input()` потребуется ввод данных. Некоторые скрипты нуждаются в подготовке входных файлов или доработке.

## Будущая организация практики

По мере необходимости можно добавлять отдельные папки `qa_lessons/`, `algorithms/` и `experiments/`; сейчас они **ещё не созданы**.

Для учебных задач с pytest полезно отдельно хранить:
- реализацию функции;
- тесты с разными техниками;
- краткое описание цели и наблюдаемого результата.

Старайся не коммитить токены, приватные ключи, персональные файлы, реальные рабочие данные или окружения.

## Процесс обучения

Ученик самостоятельно пишет и отлаживает код. ИИ может помогать с организацией репозитория, документацией, проверкой решений и наводящими вопросами. Готовые реализации учебных задач не добавляются без отдельного запроса.
